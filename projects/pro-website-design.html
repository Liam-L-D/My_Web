Designing My Personal Web Portfolio

This project showcases the ongoing development of my personal portfolio website. It serves as a platform to present my design philosophy, highlight selected works, and introduce my background and services.

The goal is to create a clean, modern, and responsive interface that reflects my identity as a designer and communicates effectively with visitors, including potential clients and employers.

The site will be coded from scratch using HTML, CSS, JavaScript, and Bootstrap, ensuring performance and flexibility across devices.

Key Design Elements

  • Responsive layouts with strong visual hierarchy
  • Focused content sections: About, Portfolio, Contact
  • Optimized for clarity, speed, and accessibility

Tools Used: Figma, Adobe XD, HTML, CSS, JavaScript, Bootstrap
