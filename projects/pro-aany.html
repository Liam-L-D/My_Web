Project

Asian Arts New York – Website & Visual Communication System

A cultural organization website project focused on event communication, content structure, responsive design, and long-term maintainability.

Overview

Website + Content System

Asian Arts New York is a cultural organization that promotes Asian arts, performances, exhibitions, and community-based cultural programs.

The goal of this project was to create a clearer digital experience that helps visitors understand the organization, explore events, and access important information more easily.

My work combined visual design, front-end development, content organization, and ongoing website maintenance to support the organization’s communication needs.

Project Focus

What this project includes

  • Responsive website design and front-end development
  • Event page structure and content organization
  • Visual hierarchy improvements for readability and navigation
  • Reusable layout sections for future updates
  • Ongoing maintenance for event and program content
Role & Tools

My Contribution

UX/UI Design, Web Design, Front-End Development, HTML, CSS, JavaScript, Bootstrap, Visual Communication

Challenge

Making cultural content easier to understand

The website needed to present a growing amount of information, including events, programs, organization details, artist content, and media updates.

The challenge was not only visual. The information had to be structured in a way that visitors could quickly scan, understand, and navigate across devices.

This required a balance between strong visual presentation and practical maintainability for future updates.

Process

How the solution was built

The project moved from content organization to visual design and then into responsive front-end implementation.

01

Structure

Organized information into clearer sections for events, programs, organization details, and visual content.

02

Design

Created a cleaner visual hierarchy with consistent spacing, typography, image presentation, and section rhythm.

03

Build & Maintain

Developed responsive page layouts and reusable components that support long-term updates and future content expansion.

Outcome

Clearer presentation and easier updates

The final website system improved how events and organizational content are presented, making the experience more readable and easier to navigate.

The redesigned structure also supports ongoing maintenance, allowing future pages and event updates to stay visually consistent.

This project reflects my ability to connect design thinking with practical front-end implementation for real organizational needs.
