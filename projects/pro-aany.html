Project

Asian Arts New York

A communication design project for a cultural organization, integrating website structure, event content, visual identity, and print materials into a unified system.

Overview

Website + Print + Event Communication


Asian Arts New York is a cultural organization dedicated to promoting Asian arts and community programs. In this project, I designed and developed the organization’s website from the ground up, along with supporting materials such as event content, posters, and a printed booklet. I approached the work as a connected system, creating a consistent visual language across both digital and print platforms.

Project Scope

What this project includes

  • Responsive website design and front-end development
  • Event page structure and content organization
  • Promotional poster design for cultural events
  • 20-page booklet layout and editorial design
  • Logo usage, typography, and visual identity consistency
  • Reusable layout sections for future updates
  • Ongoing web and visual communication support
Role & Tools

My Contribution

Visual & Communication Design, UX/UI Design, Front-End Development (HTML, CSS, JavaScript, Bootstrap), and print design including posters and booklet. Tools: Adobe Creative Suite.

Challenge

Organizing cultural content across multiple formats


The organization needed to communicate events, programs, artist content, and community updates across both digital and printed materials.

The challenge was to create a clear and consistent system that could support different communication needs — navigation, promotion, storytelling, and ongoing updates — without losing structure or visual coherence.

Solution

A flexible communication system

I treated the project as a system, ensuring consistency across website, print, and event materials.

01

Website Structure

Built responsive pages and reusable sections for events, programs, organization information, and future updates.

02

Visual Identity

Refined logo usage, color application, typography, and layout consistency across digital and print materials.

03

Print & Event Materials

Designed posters, event materials, and a 20-page booklet to support promotion and cultural storytelling.

Process

How the System Was Built

I organized content, defined a consistent visual direction, and built responsive materials that could support the organization’s ongoing communication needs.

01

Content Organization

Structured events, programs, artist information, and organizational content into clear sections for both web and print use.

02

Visual System Design

Defined typography, spacing, image placement, color, and layout hierarchy to create a consistent visual presentation.

03

Development & Maintenance

Built responsive front-end layouts and maintained event content, promotional materials, and visual assets as the project evolved.

Gallery

Selected Project Outputs

A selection of visual materials created for the organization, including promotional design, booklet layout, and event communication pieces.

Outcome

A clearer and more consistent brand experience


The final system improved how Asian Arts New York presents its events, programs, and organizational identity across digital and print materials.

The website became easier to update and navigate, while posters and booklet materials extended the organization’s communication beyond the screen.

This project reflects my ability to combine graphic design, information design, front-end development, and real organizational communication needs into one cohesive design system.
