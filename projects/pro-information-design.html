Information Design – Data to Visual Stories

Transforming Data into Visual Narratives

This project explores how raw data can be transformed into meaningful visual narratives through information design principles.

Techniques such as mapping, sequencing, and layering were applied to structure information in a clear and engaging way.

The final outcome combines visual storytelling and interaction design to improve audience understanding and engagement.

View Live Project

Key Design Elements

  • Data visualization across time and location
  • Storytelling-driven information structure
  • Interactive presentation using Prezi

Tools Used: Prezi, Adobe Illustrator
