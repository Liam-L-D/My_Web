Information Design

Data to Visual Stories

Transforming raw information into meaningful visual narratives through structure, hierarchy, storytelling, and interactive presentation.

Overview

Visualizing Information

This project explores how complex information can be transformed into clear and engaging visual narratives using information design principles.

Techniques such as mapping, sequencing, hierarchy, and layering were used to organize information in a meaningful and accessible way.

The final outcome integrates visual storytelling and interactive presentation to improve audience understanding and engagement.

View Live Project
Key Design Elements

What this project includes

  • Data visualization across time, location, and personal experience
  • Storytelling-driven structure with clear visual hierarchy
  • Mapping and timeline-based organization of information
  • Interactive presentation experiences created through Prezi and web format
