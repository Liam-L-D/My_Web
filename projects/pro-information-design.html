Information Design – Data to Visual Stories

Transforming Data into Visual Narratives

This project focuses on converting collected data into compelling visual narratives through the lens of information design.

Using techniques such as mapping, sequencing, and layering, the data is transformed into clear and engaging presentations.

These visualizations were developed using Prezi to emphasize storytelling in both educational and professional contexts.

Key Design Elements

  • Data visualization through time and location
  • Storytelling-focused presentation structure
  • Interactive Prezi-based design approach

Tools Used: Prezi, Adobe Illustrator
