Project

WAADA – Nonprofit Website Design & Development

A nonprofit website redesign project focused on clearer content structure, cultural event communication, responsive layout, and long-term website maintenance.

Overview

Nonprofit Website System

This project presents the website design and development work for Washington Art and Design Association, a nonprofit organization focused on cultural, artistic, and community-based programs.

The goal was to create a clearer and more professional online presence that helps visitors understand the organization, browse events, view galleries, and connect with its mission.

My work included page structure, responsive layout, visual consistency, event content organization, and ongoing website maintenance.

Key Design Elements

What this project includes

  • Responsive nonprofit website structure
  • Home, About, Events, Gallery, Team, and Donate pages
  • Clear event content organization and visual hierarchy
  • Consistent navigation, footer, typography, and section layout
  • Gallery presentation for community art and cultural activities
  • Ongoing updates for programs, event pages, and visual content
Tools Used

Software

Adobe Illustrator, Photoshop, HTML, CSS, JavaScript, Bootstrap

My Role

Designer + Website Maintainer

I worked on both the visual and technical sides of the website, translating the organization’s activities into a clean digital structure that is easy for visitors to understand.

Because nonprofit websites often need frequent updates, I also focused on creating reusable layouts for events, galleries, and organization content. This makes the website easier to maintain over time.

The project reflects my ability to combine graphic design, information organization, and front-end implementation into one practical communication system.
