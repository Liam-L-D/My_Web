Project

WAADA – Nonprofit Website Design & UX System

A nonprofit website project focused on clearer content structure, responsive layout, cultural event communication, and a more consistent user experience for visitors and community members.

Overview

Website + Content Structure + Maintenance


Washington Art and Design Association is a nonprofit organization that supports cultural, artistic, and community-based programs.

My work focused on improving how the organization presents its mission, events, galleries, team information, and donation content through a clearer website structure.

The project also included responsive layout design, visual consistency, event content organization, and ongoing updates so the website can continue serving the organization over time.

Project Scope

What this project includes

  • Responsive nonprofit website design and front-end development
  • Home, About, Events, Gallery, Team, and Donate page structure
  • Clear navigation, section hierarchy, and visitor flow
  • Event content organization for cultural and community programs
  • Reusable layouts for future website updates
  • Ongoing website maintenance and content support
Role & Tools

My Contribution

Web Design, UX/UI Design, Information Design, Front-End Development, Website Maintenance, HTML, CSS, JavaScript, Bootstrap, Adobe Creative Suite.

Challenge

Making nonprofit content easier to browse and update


The organization needed a website that could present many types of content, including events, galleries, team information, donation details, and community activities.

The main challenge was creating a structure that feels simple for visitors while also remaining flexible enough for future event updates and website maintenance.

Solution

A flexible website system for community communication

I treated the website as a reusable communication system instead of a set of isolated pages.

01

Website Structure

Organized the website into clear pages and sections so visitors can understand the organization, events, gallery content, and donation path.

02

User Experience

Improved navigation, spacing, section rhythm, mobile layout, and visual hierarchy to make the site easier to browse.

03

Maintenance System

Built reusable sections for events, galleries, and content updates so the website can grow with the organization’s future programs.

Process

How the website was built

The process focused on clarifying content, designing a consistent interface, and building a responsive structure that supports ongoing updates.

01

Organize

Grouped organization information, event content, gallery materials, and donation details into a clearer site structure.

02

Design

Created a consistent layout direction using typography, spacing, image placement, cards, and responsive section patterns.

03

Build & Maintain

Implemented the pages with HTML, CSS, JavaScript, and Bootstrap, then continued updating event and website content as needed.

Selected Website Screens

Outcome

A clearer and easier-to-maintain nonprofit website


The final website gives WAADA a more organized and professional online presence for sharing its mission, events, gallery content, and community work.

The site became easier for visitors to navigate and easier for the organization to update as new activities and programs are added.

This project reflects my ability to combine UX thinking, information design, responsive web development, and real nonprofit communication needs into one practical website system.
